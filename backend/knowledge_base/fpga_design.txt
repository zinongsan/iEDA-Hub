# FPGA设计与应用

## FPGA简介

**FPGA是什么**：FPGA（Field-Programmable Gate Array，现场可编程门阵列）是一种可编程的集成电路，用户可以通过硬件描述语言配置其内部逻辑功能。与ASIC不同，FPGA可以在出厂后由用户自己编程。

**FPGA的特点**：
- **可重复编程**：可以多次修改设计而无需重新制造芯片
- **快速原型验证**：从设计到实现只需几小时
- **灵活性强**：同一块FPGA可以实现不同的功能
- **并行处理**：天然的并行架构，适合高性能计算

**FPGA适用场景**：
- 小批量产品（ASIC流片成本太高）
- 需要快速迭代的项目
- 算法原型验证
- 高性能数字信号处理
- 硬件加速

## FPGA基本架构

### 1. 可配置逻辑块（CLB/Logic Element）

可配置逻辑块是FPGA的基本逻辑单元。

**主要组成**：
- **查找表（LUT）**：实现组合逻辑，通常是4输入或6输入
- **触发器（FF）**：实现时序逻辑，D触发器
- **多路器（MUX）**：选择信号路径
- **进位链（Carry Chain）**：加速加法运算

**LUT工作原理**：
- 4输入LUT = 16×1的SRAM
- 存储所有可能输入组合的输出值
- 可以实现任意4输入的布尔函数
- 例如：实现F = A·B + C·D

### 2. 可编程互连资源

**互连类型**：
- **本地互连**：连接相邻的CLB，延迟最小
- **全局互连**：连接整个芯片的资源，延迟较大
- **长线**：跨越多个CLB，适合长距离连接
- **时钟网络**：专用的低偏斜时钟分布网络

**可编程开关**：
- **SRAM开关**：使用SRAM控制晶体管开关
- **反熔丝开关**：一次性编程
- **Flash开关**：非易失性存储

### 3. I/O块（IOB）

**功能**：
- **输入缓冲**：施密特触发器，去抖动
- **输出缓冲**：三态驱动器，可调驱动强度
- **双向缓冲**：支持双向通信
- **差分信号**：支持LVDS等差分标准
- **DDR寄存器**：支持DDR I/O

**I/O标准**：
- LVCMOS：单端信号，1.2V-3.3V
- LVDS：低压差分信号，高速传输
- SSTL：存储器接口标准
- HSTL：高速收发器逻辑

### 4. 块RAM（BRAM）

**特点**：
- 双口RAM，支持同时读写
- 容量：18Kb-36Kb每块
- 可配置位宽：1-36位
- 支持真双口、简单双口、单口模式
- 可级联组成更大容量

**应用**：
- FIFO缓冲器
- 查找表（LUT）
- 数据缓存
- 帧缓存

### 5. DSP块

**功能**：
- 高性能乘法器（25×18位）
- 累加器
- 前置加法器
- 可级联实现更宽位宽
- 支持流水线操作

**应用**：
- 数字信号处理
- FIR/IIR滤波器
- FFT/DCT变换
- 矩阵运算

### 6. 时钟管理单元

**PLL（Phase-Locked Loop）**：
- 时钟倍频和分频
- 相位调整
- 抖动过滤
- 占空比调整

**MMCM（Mixed-Mode Clock Manager）**：
- 更灵活的时钟管理
- 多个独立输出
- 动态相位调整
- 频率综合

### 7. 高速收发器（SERDES）

**功能**：
- 并串转换（Serializer）
- 串并转换（Deserializer）
- 时钟数据恢复（CDR）
- 8b/10b编解码

**应用**：
- PCIe接口
- 千兆以太网
- SATA/SAS接口
- 高速视频接口

## FPGA设计流程

### 1. 设计输入

**RTL设计**：
```verilog
module led_blink (
    input wire clk,        // 50MHz
    input wire rst_n,
    output reg led
);
    reg [24:0] counter;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            counter <= 25'b0;
            led <= 1'b0;
        end else begin
            counter <= counter + 1'b1;
            if (counter == 25'd25_000_000) begin
                counter <= 25'b0;
                led <= ~led;  // 每秒翻转
            end
        end
    end
endmodule
```

**IP核使用**：
- 厂商提供的预制模块
- PLL、FIFO、RAM、DSP等
- 通过GUI配置参数
- 生成可实例化的模块

### 2. 功能仿真

**前仿真（Pre-synthesis Simulation）**：
- 验证RTL代码逻辑正确性
- 不考虑时序和延迟
- 使用测试台激励
- 波形分析

**仿真工具**：
- ModelSim
- Vivado Simulator
- Icarus Verilog（开源）
- Verilator（开源）

### 3. 综合（Synthesis）

**综合过程**：
- RTL代码转换为网表
- 映射到FPGA原语
- 逻辑优化
- 生成约束报告

**综合工具**：
- Xilinx Vivado
- Intel Quartus
- Lattice Diamond
- Yosys（开源）

### 4. 约束设置

**时序约束（SDC）**：
```tcl
# 创建时钟
create_clock -period 20.000 -name sys_clk [get_ports clk]

# 输入延迟
set_input_delay -clock sys_clk -max 5.000 [get_ports data_in]
set_input_delay -clock sys_clk -min 2.000 [get_ports data_in]

# 输出延迟
set_output_delay -clock sys_clk -max 5.000 [get_ports data_out]
set_output_delay -clock sys_clk -min 2.000 [get_ports data_out]

# 虚假路径
set_false_path -from [get_ports rst_n]

# 多周期路径
set_multicycle_path 2 -from [get_pins reg1/Q] -to [get_pins reg2/D]
```

**物理约束（XDC/UCF）**：
```tcl
# 引脚分配
set_property PACKAGE_PIN P17 [get_ports clk]
set_property PACKAGE_PIN W19 [get_ports led]

# I/O标准
set_property IOSTANDARD LVCMOS33 [get_ports clk]
set_property IOSTANDARD LVCMOS33 [get_ports led]

# 驱动强度
set_property DRIVE 12 [get_ports led]

# 上下拉电阻
set_property PULLUP true [get_ports rst_n]
```

### 5. 实现（Implementation）

**布局布线（Place & Route）**：
- **布局（Placement）**：确定逻辑单元的物理位置
- **布线（Routing）**：连接各个逻辑单元
- **优化**：满足时序约束

**实现步骤**：
1. Opt Design：设计优化
2. Place Design：布局
3. Route Design：布线
4. Phys Opt Design：物理优化

### 6. 时序分析

**静态时序分析（STA）**：
- **建立时间检查**：数据在时钟沿前稳定
- **保持时间检查**：数据在时钟沿后保持
- **时钟周期检查**：满足最小时钟周期
- **时钟偏斜分析**：时钟到达时间差异

**时序报告**：
```
Slack (MET) :             2.147ns  (required time - arrival time)
  Source:                 counter_reg[0]/C
  Destination:            counter_reg[24]/D
  Data Path Delay:        7.853ns  (logic 2.123ns  interconnect 5.730ns)
  Clock Path Skew:        0.000ns
  Clock Uncertainty:      0.035ns
```

### 7. 生成比特流

**比特流（Bitstream）**：
- 包含FPGA配置数据
- 下载到FPGA的配置文件
- 格式：.bit（Xilinx）、.sof/.pof（Intel）

**配置选项**：
- 压缩比特流
- 加密比特流
- 多启动镜像
- 配置速率

### 8. 下载和调试

**配置模式**：
- **JTAG模式**：调试用，断电丢失
- **SPI Flash模式**：永久存储，上电加载
- **SelectMAP模式**：高速配置

**在线调试**：
- **集成逻辑分析仪（ILA）**：抓取内部信号波形
- **虚拟I/O（VIO）**：运行时修改信号值
- **ChipScope/SignalTap**：第三方调试工具

## FPGA设计技巧

### 1. 时钟设计

**单时钟域设计**：
```verilog
// 使用全局时钟缓冲
BUFG clk_buf (
    .I(clk_in),
    .O(clk_global)
);
```

**多时钟域设计**：
```verilog
// 异步FIFO进行跨时钟域传输
async_fifo u_fifo (
    .wr_clk(clk_a),
    .wr_data(data_a),
    .rd_clk(clk_b),
    .rd_data(data_b)
);
```

**时钟使能**：
```verilog
// 使用时钟使能代替门控时钟
always @(posedge clk) begin
    if (clk_en) begin
        data <= data + 1;
    end
end
```

### 2. 复位设计

**异步复位，同步释放**：
```verilog
module async_rst_sync (
    input clk,
    input async_rst_n,
    output reg sync_rst_n
);
    reg rst_n_r1;

    always @(posedge clk or negedge async_rst_n) begin
        if (!async_rst_n) begin
            rst_n_r1 <= 1'b0;
            sync_rst_n <= 1'b0;
        end else begin
            rst_n_r1 <= 1'b1;
            sync_rst_n <= rst_n_r1;
        end
    end
endmodule
```

### 3. 流水线设计

**插入流水线寄存器**：
```verilog
// 长路径分割为多级流水线
always @(posedge clk) begin
    stage1 <= a * b;           // 第一级
    stage2 <= stage1 + c;      // 第二级
    result <= stage2 * d;      // 第三级
end
```

### 4. 资源复用

**时分复用**：
```verilog
// 一个乘法器分时处理多个运算
always @(posedge clk) begin
    case (state)
        2'b00: mult_result <= a0 * b0;
        2'b01: mult_result <= a1 * b1;
        2'b10: mult_result <= a2 * b2;
        2'b11: mult_result <= a3 * b3;
    endcase
end
```

### 5. 块RAM使用

**推断BRAM**：
```verilog
module ram_infer #(
    parameter ADDR_WIDTH = 10,
    parameter DATA_WIDTH = 8
)(
    input clk,
    input we,
    input [ADDR_WIDTH-1:0] addr,
    input [DATA_WIDTH-1:0] din,
    output reg [DATA_WIDTH-1:0] dout
);
    reg [DATA_WIDTH-1:0] mem [0:(1<<ADDR_WIDTH)-1];

    always @(posedge clk) begin
        if (we)
            mem[addr] <= din;
        dout <= mem[addr];  // 必须有输出寄存器
    end
endmodule
```

### 6. DSP48使用

**手动实例化DSP48**：
```verilog
DSP48E1 #(
    .A_INPUT("DIRECT"),
    .B_INPUT("DIRECT"),
    .USE_MULT("MULTIPLY"),
    .USE_PATTERN_DETECT("NO_PATDET")
) dsp_inst (
    .CLK(clk),
    .A(a),
    .B(b),
    .C(c),
    .P(result),
    .OPMODE(7'b0000101)  // P = (A*B) + C
);
```

## FPGA与ASIC对比

| 特性 | FPGA | ASIC |
|------|------|------|
| 开发周期 | 短（周-月） | 长（月-年） |
| 开发成本 | 低 | 高（流片费用） |
| 单片成本 | 高 | 低（大批量） |
| 性能 | 中等 | 高 |
| 功耗 | 较高 | 低 |
| 灵活性 | 可重配置 | 固定 |
| 上市时间 | 快 | 慢 |
| 适用场景 | 小批量、多变 | 大批量、稳定 |
