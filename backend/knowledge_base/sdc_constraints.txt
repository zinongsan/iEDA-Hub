# SDC约束完整教程

## 什么是SDC？

**SDC是什么**：SDC（Synopsys Design Constraints）是一种标准的时序约束格式，用于定义数字电路的时序要求。它是EDA工具理解设计师意图的语言，告诉工具如何优化和验证电路。

**SDC的作用**：SDC文件描述了电路必须满足的时序约束，包括时钟频率、输入输出延迟、时钟关系等。它最初由Synopsys开发，现已成为行业标准，被几乎所有主流EDA工具支持。

**为什么SDC很重要**：没有正确的SDC约束，EDA工具就不知道如何优化你的设计，可能导致芯片无法在目标频率下工作，或者过度优化浪费面积和功耗。

## 为什么需要SDC约束？

### 核心目的

1. **指导综合**：告诉综合工具优化目标（速度、面积、功耗）
2. **指导布局布线**：确保物理实现满足时序要求
3. **验证时序**：静态时序分析（STA）的依据
4. **约束接口**：定义芯片与外部器件的时序关系

### 没有SDC会怎样？

- ❌ 综合工具无法优化关键路径
- ❌ 布局布线可能不满足时序
- ❌ 无法进行准确的时序分析
- ❌ 芯片可能无法在目标频率下工作

## SDC文件基本结构

```tcl
# ===================================
# 1. 时钟定义
# ===================================
create_clock -period 10 -name clk [get_ports clk]

# ===================================
# 2. 输入输出延迟
# ===================================
set_input_delay -clock clk -max 2.0 [get_ports data_in]
set_output_delay -clock clk -max 1.5 [get_ports data_out]

# ===================================
# 3. 时钟特性
# ===================================
set_clock_uncertainty 0.5 [get_clocks clk]
set_clock_latency 1.0 [get_clocks clk]

# ===================================
# 4. 环境条件
# ===================================
set_load 0.05 [get_ports data_out]
set_driving_cell -lib_cell BUFX2 [get_ports data_in]

# ===================================
# 5. 设计规则约束
# ===================================
set_max_fanout 10 [current_design]
set_max_transition 0.5 [current_design]
```

## 核心命令详解

### 1. create_clock - 创建时钟

**基本语法**：
```tcl
create_clock -period <周期> -name <名称> [时钟源]
```

**示例**：

```tcl
# 创建10ns周期的时钟（100MHz）
create_clock -period 10 -name sys_clk [get_ports clk]

# 创建5ns周期的时钟（200MHz）
create_clock -period 5 -name fast_clk [get_ports clk2]

# 指定占空比（默认50%）
create_clock -period 10 -waveform {0 3} -name clk [get_ports clk]
# 波形：0-3ns为高电平，3-10ns为低电平（30%占空比）
```

**关键参数**：
- `-period`：时钟周期（ns）
- `-name`：时钟名称（可选但推荐）
- `-waveform {rising falling}`：波形定义
- `-add`：为同一端口添加多个时钟（用于多频时钟）

### 2. create_generated_clock - 派生时钟

用于定义由分频器、倍频器、门控时钟等产生的时钟。

**示例**：

```tcl
# 二分频时钟
create_generated_clock -name clk_div2 \
  -source [get_ports clk] \
  -divide_by 2 \
  [get_pins div_reg/Q]

# 倍频时钟
create_generated_clock -name clk_mul2 \
  -source [get_ports clk] \
  -multiply_by 2 \
  [get_pins pll/clk_out]

# 门控时钟
create_generated_clock -name clk_gated \
  -source [get_ports clk] \
  -master_clock sys_clk \
  [get_pins clk_gate/Q]
```

### 3. set_input_delay - 输入延迟

定义输入数据相对于时钟的到达时间。

**概念图**：
```
外部芯片时钟 → 外部芯片输出延迟 → PCB走线延迟 → 本芯片输入端口
                                                    ↑
                                           这段时间就是input_delay
```

**语法**：
```tcl
set_input_delay -clock <时钟> -max <最大延迟> [端口]
set_input_delay -clock <时钟> -min <最小延迟> [端口]
```

**示例**：

```tcl
# 基本用法
set_input_delay -clock clk -max 2.0 [get_ports data_in]
set_input_delay -clock clk -min 0.5 [get_ports data_in]

# 批量设置
set_input_delay -clock clk -max 2.0 [get_ports data_*]

# 不同时钟沿
set_input_delay -clock clk -clock_fall -max 1.0 [get_ports data_in]
# 在时钟下降沿采样的数据

# 添加网络延迟
set_input_delay -clock clk -max 2.0 -add_delay [get_ports data_in]
```

**如何计算input_delay？**

```
input_delay_max = Tco_max(外部芯片) + Tpcb_max(板级走线)
input_delay_min = Tco_min(外部芯片) + Tpcb_min(板级走线)

例如：
外部芯片Tco_max = 3ns, Tco_min = 1ns
PCB走线延迟 = 0.5ns
则：
  input_delay_max = 3 + 0.5 = 3.5ns
  input_delay_min = 1 + 0.5 = 1.5ns
```

### 4. set_output_delay - 输出延迟

定义输出数据需要满足的建立/保持时间。

**概念图**：
```
本芯片输出端口 → PCB走线延迟 → 外部芯片输入建立/保持时间
                                    ↑
                           这段时间就是output_delay
```

**示例**：

```tcl
# 基本用法
set_output_delay -clock clk -max 1.5 [get_ports data_out]
set_output_delay -clock clk -min -0.5 [get_ports data_out]
# min为负表示外部芯片的保持时间很小

# 批量设置
set_output_delay -clock clk -max 1.5 [get_ports q_*]

# 参考外部时钟
set_output_delay -clock clk_out -max 2.0 [get_ports data_out]
```

**如何计算output_delay？**

```
output_delay_max = Tpcb_max + Tsu(外部芯片)
output_delay_min = Tpcb_min - Th(外部芯片)

例如：
外部芯片Tsu = 2ns, Th = 0.5ns
PCB走线延迟 = 0.5ns
则：
  output_delay_max = 0.5 + 2 = 2.5ns
  output_delay_min = 0.5 - 0.5 = 0ns
```

### 5. set_clock_uncertainty - 时钟不确定性

包括时钟抖动（jitter）和偏斜（skew）。

**示例**：

```tcl
# 所有路径的不确定性
set_clock_uncertainty 0.5 [get_clocks clk]

# 建立时间和保持时间分别设置
set_clock_uncertainty -setup 0.5 [get_clocks clk]
set_clock_uncertainty -hold 0.2 [get_clocks clk]

# 跨时钟域
set_clock_uncertainty 0.8 -from clk1 -to clk2
```

**经验值**：
- **片上时钟**：0.1-0.3ns
- **外部晶振**：0.3-0.5ns
- **PLL输出**：0.05-0.15ns
- **跨时钟域**：时钟周期的5-10%

### 6. set_clock_latency - 时钟延迟

从时钟源到寄存器时钟端的延迟。

**示例**：

```tcl
# 源延迟（时钟树综合前）
set_clock_latency -source 1.0 [get_clocks clk]

# 网络延迟（时钟树综合后会被实际值替换）
set_clock_latency 0.5 [get_clocks clk]

# 早延迟和晚延迟
set_clock_latency -source -early 0.8 [get_clocks clk]
set_clock_latency -source -late 1.2 [get_clocks clk]
```

### 7. set_clock_groups - 时钟组

定义异步或逻辑互斥的时钟。

**示例**：

```tcl
# 异步时钟（不进行时序检查）
set_clock_groups -asynchronous \
  -group [get_clocks clk1] \
  -group [get_clocks clk2]

# 逻辑互斥时钟（多路选择的时钟）
set_clock_groups -logically_exclusive \
  -group [get_clocks clk_mode1] \
  -group [get_clocks clk_mode2]

# 物理互斥（不同工作模式）
set_clock_groups -physically_exclusive \
  -group [get_clocks clk_test] \
  -group [get_clocks clk_func]
```

### 8. set_false_path - 假路径

标记不需要时序检查的路径。

**示例**：

```tcl
# 跨异步时钟域
set_false_path -from [get_clocks clk1] -to [get_clocks clk2]

# 特定信号
set_false_path -from [get_ports rst_n]

# 特定起点到终点
set_false_path -from [get_pins config_reg/Q] -to [get_ports led]

# 通过某个中间点
set_false_path -through [get_pins mux_debug/S]
```

**何时使用false_path？**
- 异步复位信号
- 测试/调试信号
- 配置寄存器到非关键路径
- 异步时钟域交互（应配合同步器）

### 9. set_multicycle_path - 多周期路径

允许路径使用多个时钟周期完成。

**示例**：

```tcl
# 数据需要2个周期到达
set_multicycle_path -setup 2 \
  -from [get_pins mult/Q] \
  -to [get_pins result_reg/D]

# 相应的保持时间调整
set_multicycle_path -hold 1 \
  -from [get_pins mult/Q] \
  -to [get_pins result_reg/D]
```

**规则**：
- setup的multicycle = N，则hold应该设为N-1
- 典型场景：乘法器、除法器、复杂ALU

### 10. set_max_delay / set_min_delay - 延迟约束

直接指定路径的最大/最小延迟。

**示例**：

```tcl
# 最大延迟5ns
set_max_delay 5.0 -from [get_ports a] -to [get_ports b]

# 最小延迟0.5ns（防止保持时间违例）
set_min_delay 0.5 -from [get_ports a] -to [get_ports b]

# 组合逻辑路径
set_max_delay 3.0 -from [all_inputs] -to [all_outputs]
```

### 11. set_load - 设置负载

定义输出端口的电容负载。

**示例**：

```tcl
# 单位：pF
set_load 0.05 [get_ports data_out]

# 批量设置
set_load 0.03 [all_outputs]

# 使用net capacitance
set_load -pin_load 0.02 [get_ports clk_out]
set_load -wire_load 0.01 [get_ports clk_out]
```

### 12. set_driving_cell - 驱动单元

定义输入端口的驱动强度。

**示例**：

```tcl
# 使用标准单元库中的buffer
set_driving_cell -lib_cell BUFX2 -library std_cell [get_ports data_in]

# 指定驱动引脚
set_driving_cell -lib_cell DFF -pin Q [get_ports data_in]

# 批量设置
set_driving_cell -lib_cell BUFX4 [all_inputs]
```

## 完整SDC示例

### 示例1：简单SoC

```tcl
# ===================================
# 基本信息
# ===================================
# 设计：simple_soc
# 主频：100MHz (10ns)
# 工艺：28nm
# ===================================

# 创建主时钟
create_clock -period 10 -name sys_clk [get_ports clk]

# 创建派生时钟（50MHz）
create_generated_clock -name clk_50 \
  -source [get_ports clk] \
  -divide_by 2 \
  [get_pins clk_div/Q]

# 时钟不确定性
set_clock_uncertainty -setup 0.3 [get_clocks sys_clk]
set_clock_uncertainty -hold 0.1 [get_clocks sys_clk]

# 时钟延迟（综合前估算）
set_clock_latency -source 1.0 [get_clocks sys_clk]
set_clock_latency 0.5 [get_clocks sys_clk]

# 输入约束
set_input_delay -clock sys_clk -max 2.0 [get_ports data_in*]
set_input_delay -clock sys_clk -min 0.5 [get_ports data_in*]

# 输出约束
set_output_delay -clock sys_clk -max 1.5 [get_ports data_out*]
set_output_delay -clock sys_clk -min -0.5 [get_ports data_out*]

# 复位信号（假路径）
set_false_path -from [get_ports rst_n]

# 环境条件
set_load 0.05 [all_outputs]
set_driving_cell -lib_cell BUFX2 [all_inputs]

# 设计规则
set_max_fanout 16 [current_design]
set_max_transition 0.5 [current_design]
set_max_capacitance 0.1 [current_design]
```

### 示例2：多时钟域设计

```tcl
# 创建多个时钟
create_clock -period 5 -name clk_cpu [get_ports clk_cpu]
create_clock -period 10 -name clk_bus [get_ports clk_bus]
create_clock -period 20 -name clk_periph [get_ports clk_periph]

# 定义异步时钟组
set_clock_groups -asynchronous \
  -group [get_clocks clk_cpu] \
  -group [get_clocks clk_bus] \
  -group [get_clocks clk_periph]

# 或者逐一设置假路径
set_false_path -from [get_clocks clk_cpu] -to [get_clocks clk_bus]
set_false_path -from [get_clocks clk_bus] -to [get_clocks clk_cpu]
# ... 其他组合

# CDC（跨时钟域）路径应该有同步器
# 同步器后的路径可以设置假路径
set_false_path -from [get_pins sync_reg[0]/Q] -to [get_pins sync_reg[1]/D]
```

### 示例3：DDR接口

```tcl
# DDR时钟（400MHz，2.5ns）
create_clock -period 2.5 -name ddr_clk [get_ports ddr_ck_p]

# 数据选通信号DQS
create_clock -period 2.5 -name ddr_dqs [get_ports ddr_dqs]

# DQS是DDR_CLK的派生时钟
set_clock_groups -physically_exclusive \
  -group [get_clocks ddr_clk] \
  -group [get_clocks ddr_dqs]

# 输入数据相对于DQS（中心对齐）
set_input_delay -clock ddr_dqs -max 0.6 [get_ports ddr_dq*]
set_input_delay -clock ddr_dqs -min -0.6 [get_ports ddr_dq*]
set_input_delay -clock ddr_dqs -max 0.6 -clock_fall -add_delay [get_ports ddr_dq*]
set_input_delay -clock ddr_dqs -min -0.6 -clock_fall -add_delay [get_ports ddr_dq*]

# 输出数据相对于CLK
set_output_delay -clock ddr_clk -max 0.8 [get_ports ddr_dq*]
set_output_delay -clock ddr_clk -min -0.8 [get_ports ddr_dq*]
set_output_delay -clock ddr_clk -max 0.8 -clock_fall -add_delay [get_ports ddr_dq*]
set_output_delay -clock ddr_clk -min -0.8 -clock_fall -add_delay [get_ports ddr_dq*]
```

## 常见错误和调试

### 错误1：忘记定义时钟

**现象**：时序报告显示"unconstrained paths"

**解决**：
```tcl
# 检查未约束的路径
report_timing -from [all_registers] -to [all_registers]

# 补充时钟定义
create_clock -period 10 -name clk [get_ports clk]
```

### 错误2：跨时钟域未处理

**现象**：时序违例，且路径跨越不同时钟

**解决**：
```tcl
# 如果是异步时钟，设置假路径
set_false_path -from [get_clocks clk1] -to [get_clocks clk2]

# 或定义时钟组
set_clock_groups -asynchronous \
  -group [get_clocks clk1] \
  -group [get_clocks clk2]
```

### 错误3：Input/Output delay设置错误

**现象**：接口时序违例

**解决**：
```tcl
# 重新计算input_delay
# input_delay = 外部器件Tco + 板级延迟

# 重新计算output_delay
# output_delay = 板级延迟 + 外部器件Tsu
```

### 错误4：时钟不确定性过大或过小

**现象**：时序过于悲观或过于乐观

**解决**：
```tcl
# 根据实际测量的jitter调整
set_clock_uncertainty 0.3 [get_clocks clk]

# 或咨询时钟IP厂商的datasheet
```

## 最佳实践

### 1. 分层约束

```tcl
# top.sdc - 顶层约束
source clocks.sdc
source inputs.sdc
source outputs.sdc
source exceptions.sdc
```

### 2. 使用变量

```tcl
# 定义变量便于维护
set CLK_PERIOD 10
set INPUT_DELAY [expr $CLK_PERIOD * 0.2]
set OUTPUT_DELAY [expr $CLK_PERIOD * 0.15]

create_clock -period $CLK_PERIOD -name clk [get_ports clk]
set_input_delay -clock clk -max $INPUT_DELAY [all_inputs]
```

### 3. 注释清晰

```tcl
# ===================================
# 时钟定义
# 系统主频: 100MHz
# 来源: 外部晶振
# ===================================
create_clock -period 10 -name sys_clk [get_ports clk]
```

### 4. 验证约束

```tcl
# 检查时钟定义
report_clocks

# 检查未约束路径
report_timing -unconstrained

# 检查时钟交互
report_clock_interaction
```

## 工具差异

虽然SDC是标准格式，但不同工具有细微差异：

### Synopsys (Design Compiler, PrimeTime)
- 最完整的SDC支持
- 所有命令都支持
- 是SDC的制定者

### Cadence (Genus, Tempus)
- 完整支持SDC
- 部分命令语法略有差异
- 有自己的扩展（如set_clock_sense）

### Xilinx (Vivado)
- 基于SDC，但称为XDC
- 添加了FPGA特有命令
- 部分命令参数不同

### Intel (Quartus)
- 支持SDC
- 也有自己的TimeQuest约束格式
- 建议使用SDC以保持兼容性

## 总结

SDC约束是数字IC设计的核心：

- ✅ **标准化**：行业标准，工具通用
- ✅ **完整性**：覆盖所有时序场景
- ✅ **灵活性**：支持复杂设计
- ⚠️ **复杂性**：需要深入理解时序分析
- ⚠️ **工具差异**：不同工具有细微差异

**记住**：正确的SDC约束是芯片成功tape-out的基础！
