
# 数字电路设计基础

## 逻辑门

逻辑门是数字电路的基本构建模块。

### 基本逻辑门

1. **与门（AND）**：只有所有输入都为1时，输出才为1
2. **或门（OR）**：任何输入为1时，输出就为1
3. **非门（NOT）**：输出是输入的反向
4. **异或门（XOR）**：输入不同时输出为1
5. **与非门（NAND）**：与门的输出取反，是通用门
6. **或非门（NOR）**：或门的输出取反，也是通用门

### 组合逻辑电路

组合逻辑电路的输出只依赖于当前输入，不依赖历史状态。

**常见组合电路**：
- 加法器
- 译码器
- 编码器
- 多路选择器
- 比较器

### 时序逻辑电路

时序逻辑电路的输出不仅依赖当前输入，还依赖电路的历史状态。

**存储元件**：
- **D触发器**：在时钟边沿锁存数据
- **JK触发器**：功能更强大的触发器
- **寄存器**：多个触发器组成，存储多位数据
- **计数器**：按特定顺序计数

## 有限状态机（FSM）

FSM是时序电路设计的核心概念。

### Moore型状态机
输出只依赖于当前状态。

### Mealy型状态机
输出依赖于当前状态和输入。

### FSM设计步骤
1. 状态定义
2. 状态转移条件
3. 输出逻辑
4. 编码实现（Verilog）
5. 仿真验证

## Verilog基础

Verilog是硬件描述语言，用于设计数字电路。

### 基本语法
```verilog
// 模块定义
module adder(
    input [3:0] a,
    input [3:0] b,
    output [4:0] sum
);
    assign sum = a + b;
endmodule
```

### 阻塞赋值与非阻塞赋值
- **阻塞赋值（=）**：用于组合逻辑
- **非阻塞赋值（<=）**：用于时序逻辑

### 常用语句
- always块：描述时序或组合逻辑
- case语句：多路选择
- if-else：条件判断

## 设计实践

### 设计原则
1. **同步设计**：使用统一时钟
2. **避免锁存器**：明确所有路径的赋值
3. **复位设计**：提供可靠的初始化
4. **时序约束**：设置合理的时钟周期
5. **代码规范**：保持良好的编码风格

### 常见错误
- 组合逻辑环路
- 多驱动信号
- 时序违例
- 功能仿真与实际不符

### 调试技巧
1. 波形分析
2. 打印关键信号
3. 分模块验证
4. 使用断言（assertion）
