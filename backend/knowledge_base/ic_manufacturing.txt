# 集成电路制造工艺

## 半导体制造概述

集成电路（IC）制造是将设计好的电路图转换为实际芯片的过程，主要在晶圆厂（Fab）进行。现代芯片制造工艺复杂，需要数百道工序，历时数月。

## CMOS工艺基础

### 1. 硅晶圆制备

**单晶硅生长**：
- **Czochralski法（CZ法）**：从硅熔体中拉出单晶硅棒
- **直径**：200mm（8英寸）、300mm（12英寸）、450mm（未来）
- **晶向**：<100>或<111>晶向
- **掺杂**：N型（磷掺杂）或P型（硼掺杂）

**晶圆加工**：
- 切片：将硅棒切成薄片（厚度约0.7mm）
- 研磨：使晶圆表面平整
- 抛光：达到镜面效果
- 清洗：去除杂质和颗粒

### 2. 氧化（Oxidation）

在硅表面生长二氧化硅（SiO₂）薄膜。

**氧化方法**：
- **热氧化（Thermal Oxidation）**
  - 干氧氧化：Si + O₂ → SiO₂（致密，生长慢）
  - 湿氧氧化：Si + 2H₂O → SiO₂ + 2H₂（疏松，生长快）
  - 温度：900-1200°C

**氧化膜用途**：
- 栅氧化层：MOS晶体管的栅极绝缘层
- 场氧化层：隔离相邻器件
- 掩膜层：保护某些区域不被刻蚀或离子注入
- 钝化层：保护芯片表面

**氧化膜厚度控制**：
- 栅氧化层：1-5nm（先进工艺使用高k介质）
- 场氧化层：几百纳米

### 3. 光刻（Photolithography）

将设计图案转移到晶圆表面的过程，是IC制造中最关键的步骤。

**光刻步骤**：
1. **涂光刻胶**：旋涂光敏材料
   - 正胶：曝光区域可溶解
   - 负胶：曝光区域不可溶解
   - 厚度：0.5-2μm

2. **软烘焙**：去除溶剂，使光刻胶固化

3. **对准曝光**：
   - 使用光刻机（Stepper或Scanner）
   - 通过掩膜版（Mask）将图案投影到晶圆
   - 光源：DUV（193nm）、EUV（13.5nm极紫外）

4. **显影**：
   - 溶解掉可溶区域
   - 留下图案化的光刻胶

5. **硬烘焙**：增强光刻胶的耐刻蚀能力

6. **检查**：光学显微镜或SEM检查图案质量

**分辨率限制**：
- 瑞利判据：R = k₁ × λ / NA
  - λ：光源波长
  - NA：数值孔径
  - k₁：工艺因子（约0.25-0.3）

**先进光刻技术**：
- **浸没式光刻（Immersion）**：在镜头和晶圆间填充液体，提高NA
- **多重图形（Multi-patterning）**：
  - 双重图形（LELE, SADP）
  - 三重图形（LELELE, SAQP）
  - 7nm及以下必须使用
- **EUV光刻**：使用13.5nm极紫外光，单次曝光达到更精细线宽

### 4. 刻蚀（Etching）

去除未被光刻胶保护区域的材料。

**湿法刻蚀**：
- 使用化学溶液
- 各向同性刻蚀
- 精度较低
- 成本低，适合非关键层

**干法刻蚀（等离子刻蚀）**：
- **反应离子刻蚀（RIE）**：
  - 物理+化学作用
  - 各向异性刻蚀
  - 高精度，适合高深宽比结构

- **深反应离子刻蚀（DRIE）**：
  - 刻蚀深度可达数百微米
  - 用于MEMS器件

**刻蚀选择比**：
- 目标材料与掩膜材料的刻蚀速率比
- 选择比越高，掩膜越薄，成本越低

### 5. 离子注入（Ion Implantation）

将杂质离子注入硅衬底，形成N型或P型半导体区域。

**离子注入过程**：
1. 离子源产生离子
2. 加速离子（能量10keV-1MeV）
3. 质量分析器选择特定离子
4. 扫描注入晶圆

**常用掺杂剂**：
- **N型**：磷（P）、砷（As）
- **P型**：硼（B）、铟（In）

**离子注入优势**：
- 精确控制剂量和深度
- 室温操作，不损伤晶圆
- 可注入难以扩散的杂质

**退火（Annealing）**：
- 修复注入造成的晶格损伤
- 激活杂质原子（使其进入替位位置）
- 快速热退火（RTA）：1000°C，几秒到几十秒

### 6. 薄膜沉积（Thin Film Deposition）

在晶圆表面沉积各种材料薄膜。

**化学气相沉积（CVD）**：
- **常压CVD（APCVD）**：在大气压下沉积
- **低压CVD（LPCVD）**：低压（0.1-1 Torr），均匀性好
- **等离子增强CVD（PECVD）**：低温沉积（200-400°C）
- **原子层沉积（ALD）**：逐原子层生长，保形性极好

**物理气相沉积（PVD）**：
- **溅射（Sputtering）**：
  - 用高能离子轰击靶材
  - 靶材原子溅射到晶圆表面
  - 用于金属层（Al, Cu, Ti, TiN等）

- **蒸发（Evaporation）**：
  - 加热材料使其蒸发
  - 蒸汽凝聚在晶圆表面
  - 成本低，但台阶覆盖差

**常见薄膜材料**：
- **介质**：SiO₂, Si₃N₄, low-k材料
- **金属**：Al, Cu, W, Ti, TiN, Ta, TaN
- **多晶硅**：栅极、电阻
- **高k介质**：HfO₂, ZrO₂（替代栅氧化层）

### 7. 化学机械抛光（CMP）

平坦化晶圆表面，去除多余材料。

**CMP原理**：
- 化学作用：抛光液软化材料
- 机械作用：抛光垫研磨材料
- 同时进行化学和机械作用

**应用**：
- 金属CMP：铜镶嵌工艺中去除多余铜
- 氧化物CMP：平坦化介质层
- STI CMP：浅沟槽隔离工艺

**CMP挑战**：
- 均匀性控制
- 腐蚀控制
- 缺陷控制（划痕、残留）

## 先进工艺节点技术

### 1. FinFET技术（22nm及以下）

**FinFET结构**：
- 立体栅极包围鳍状沟道
- 三面栅控，抑制短沟道效应
- 更低的漏电流
- 更好的亚阈值特性

**制造挑战**：
- Fin的刻蚀精度要求极高
- 栅极与Fin的对准
- Fin间距的均匀性

### 2. 铜互连（0.18μm及以下）

**铜镶嵌工艺（Damascene）**：
1. 沉积介质层
2. 刻蚀沟槽和通孔
3. 沉积阻挡层（Ta/TaN）
4. 电镀铜填充
5. CMP去除多余铜

**双镶嵌工艺**：
- 同时形成通孔和导线
- 减少工艺步骤
- 降低寄生电阻

**低k介质**：
- 减小互连电容
- 提高信号速度
- 降低功耗

### 3. 高k金属栅（45nm及以下）

**传统问题**：
- SiO₂栅氧化层太薄（<2nm）导致漏电严重
- 多晶硅栅极空乏效应影响性能

**解决方案**：
- **高k介质**：HfO₂（k≈25）替代SiO₂（k≈3.9）
- **金属栅**：TiN等金属替代多晶硅
- 等效氧化层厚度（EOT）<1nm，物理厚度>2nm

### 4. 应变硅技术

**应变方法**：
- **全局应变**：在SiGe衬底上生长硅
- **局部应变**：应力记忆技术（SMT）、应力衬里
- **埋入式SiGe源漏**：PMOS应变增强

**效果**：
- NMOS：拉伸应变提高电子迁移率
- PMOS：压缩应变提高空穴迁移率
- 性能提升15%-30%

### 5. 多重图形技术

**LELE（Litho-Etch-Litho-Etch）**：
- 两次光刻，两次刻蚀
- 分别形成交替的线条
- 有效线宽减半

**SADP（Self-Aligned Double Patterning）**：
1. 光刻形成核心图案
2. 沉积侧墙spacer
3. 去除核心，留下两倍密度的图案
4. 刻蚀转移

**SAQP（Self-Aligned Quadruple Patterning）**：
- 在SADP基础上再做一次
- 密度提高4倍
- 用于7nm及以下节点

### 6. EUV光刻

**优势**：
- 13.5nm波长，单次曝光更精细图案
- 减少多重图形次数
- 简化工艺流程

**挑战**：
- 光源功率（需要250W以上）
- 掩膜版缺陷（无保护膜）
- 光刻胶灵敏度和分辨率
- 成本高昂

**应用**：
- 7nm及以下节点的关键层
- 5nm、3nm节点更广泛应用

## 制造良率

### 1. 良率定义

**晶圆良率**：
- 良品芯片数 / 总芯片数
- 受缺陷密度、芯片面积影响

**Murphy良率模型**：
- Y = e^(-AD)
  - A：芯片面积
  - D：缺陷密度
  - Y：良率

### 2. 缺陷来源

**颗粒（Particles）**：
- 空气中的尘埃
- 设备产生的颗粒
- 晶圆传输过程掉落

**工艺缺陷**：
- 光刻对准不良
- 刻蚀过度或不足
- 薄膜厚度不均
- CMP划痕

**材料缺陷**：
- 硅晶圆晶格缺陷
- 金属污染
- 掩膜版缺陷

### 3. 良率提升方法

**洁净室管理**：
- Class 1洁净室（每立方英尺<1个0.5μm颗粒）
- 正压环境
- 层流气流
- 人员穿着无尘服

**统计过程控制（SPC）**：
- 实时监控工艺参数
- 检测异常趋势
- 及时调整工艺

**缺陷检测**：
- 光学检测（Optical Inspection）
- 扫描电镜（SEM）检测
- 电学测试

**设计规则优化**：
- 增大关键尺寸裕量
- 避免复杂图案
- 冗余设计

## 晶圆测试

### 1. 参数测试

**关键参数**：
- 阈值电压（Vth）
- 饱和电流（Idsat）
- 漏电流（Ioff）
- 栅氧化层厚度

**测试结构**：
- PCM（Process Control Monitor）
- Test Key结构
- 分布在晶圆各处

### 2. 功能测试

**晶圆探针测试（CP, Chip Probing）**：
- 使用探针卡接触晶圆焊盘
- 测试每个芯片的功能
- 标记坏芯片

**测试覆盖率**：
- Stuck-at测试
- 时序测试
- 功能测试
- IDDQ测试（静态电流测试）

## 封装技术

### 1. 传统封装

**DIP（Dual In-line Package）**：
- 双列直插封装
- 引脚数较少
- 成本低

**QFP（Quad Flat Package）**：
- 四边引脚封装
- 引脚数中等（44-256）
- 表面贴装

**BGA（Ball Grid Array）**：
- 球栅阵列封装
- 引脚数多（>500）
- 电气性能好

### 2. 先进封装

**Flip Chip**：
- 芯片倒装，焊球直接连接
- 缩短互连距离
- 提高性能

**2.5D封装**：
- 使用Interposer中介层
- 多个芯片并排放置
- HBM内存使用

**3D封装**：
- 芯片垂直堆叠
- TSV（Through-Silicon Via）互连
- 最小化互连长度

**SiP（System in Package）**：
- 多个芯片集成在一个封装内
- 异构集成
- 小型化

**Chiplet**：
- 多个小芯片通过先进封装互连
- 提高良率
- 降低成本
- 混合不同工艺节点

## 晶圆厂

### 主要晶圆厂：
- **TSMC（台积电）**：全球最大晶圆代工厂，技术领先
- **Samsung（三星）**：存储器+逻辑芯片
- **Intel**：IDM模式，自产自销，逐步开放代工
- **SMIC（中芯国际）**：中国最大晶圆厂
- **GlobalFoundries**：AMD分拆，停止7nm以下研发
- **UMC（联电）**：台湾第二大晶圆代工厂

### 晶圆厂建设成本：
- **12英寸28nm厂**：30-50亿美元
- **12英寸7nm厂**：100-150亿美元
- **12英寸3nm厂**：200亿美元以上

3. **关注技术发展**：新工艺节点、新技术
4. **参观晶圆厂**：实地了解制造过程
5. **阅读文献**：IEDM、ISSCC等会议论文
